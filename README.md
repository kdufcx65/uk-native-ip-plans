## 原生IP、住宅IP、双ISP，说的不是同一件事

这三个词经常被混着用，但它们描述的其实是 IP 的三个不同层面。

**原生 IP** 讲的是归属：这段 IP 由英国本土 ISP 分配，ipinfo 这类库查出来归属地是英国，不是机房托管段。它解决的是“地理位置对不对”的问题。

**住宅 IP** 讲的是来源：IP 出自英国家庭宽带运营商，比如 Virgin Media、Sky Broadband、BT 这些名字。平台风控看到的不是“某云厂商的客户”，而是“某个家庭宽带用户在上网”。它解决的是“像不像真人”的问题。

**双 ISP** 讲的是冗余：IP 的注册信息和路由归属分别落在两家不同的英国本土 ISP 身上，比单 ISP 更难被判成代理。它解决的是“抗不抗查”的问题。

机房 IP 的问题出在第一层就崩了。ASN 一查就是云服务商，TikTok 的风控、BBC 的区域检测、亚马逊的登录异常判定，都会优先盯这类地址段。你后面再怎么换浏览器指纹、清 Cookie，底层那个“我是机房”的标签没变。

自己验的方法很简单：拿到 IP 后丢进 ipinfo，看 ASN 那一行的组织名。写着 Virgin Media、Sky、BT 这类家庭宽带运营商，说明走的是住宅路线；写着某云计算、某 IDC，那就是机房段，参数表上写什么都救不回来。

丽萨主机这条英国线现在用的是 Virgin Media O2 的家宽原生 IP，ipinfo 显示双 ISP 属性，归属伦敦。这条线不是一开始就长这样：早期用 Cogent 的 ISP 段，后来换成 Vorboss，现在这版才真正落到英国家庭宽带的属性上。对买的人来说，这意味着“英国原生 IP”这个说法在这条产品线上是有具体指向的，不是一句营销词。

需要提前说清楚的一点：住宅 IP 能把被风控的概率压低，但没有任何商家能保证账号 100% 不被限流。声称“绝对不封号”的说法本身就不值得信。IP 是降低风险的一环，业务本身合不合规是另一环。
